## Description

This repository contains the slides for my talk on the quality of a priori power analyses reported in Sports and Exercise Science research.

The slides are available here: [Oslo Metasicence Symposium talk](https://cristianmesquida.github.io/metascience_symposium_oslo/)

## Repository structure

```text
metascience_symposium_oslo/
├── README.md                  # Repository overview and links
├── index.qmd                  # Quarto source for the slides
├── index.html                 # Rendered slides
├── index_files/               # Supporting files generated by Quarto for the HTML presentation
├── references.bib             # Bibliography
└── figures/                   # Figures used in the slides
```
