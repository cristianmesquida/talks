## Description

This repository contain the slides for my talk on [*Metacheck*](https://www.scienceverse.org/metacheck/), presented at the **Transparency, Technology and AI in Peer Review** conference at Eindhoven University of Technology.

The slides are available here: [TU/e conference talk](https://cristianmesquida.github.io/technology_tue_conference_talk/)

## Repository structure

```text
repository/
├── README.md                  # Repository overview and links
├── index.qmd                  # Quarto source for the presentation
├── index.html                 # Rendered HTML presentation (GitHub Pages)
├── presentation.tex           # LaTeX source for the presentation
├── styles.css                 # Custom CSS for the presentation
├── _extensions/               # Quarto extensions
├── figures/                   # Figures used in the presentation
├── presentation_files/        # HTML dependencies generated by Quarto
└── report_files/              # Supplementary report files
```
